## What it does

A small Python program (stdlib only) writes exactly two lines to `/output/entry.txt`:

1. Line one warns the writer's past self about one specific moment, in a single sentence.
2. Line two says in one sentence why that moment mattered and what changed because of it.

The program validates its own output before writing: exactly 2 lines, 1–280 total characters, one sentence per line, valid UTF-8.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
